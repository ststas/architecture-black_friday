# pymongo-api

## Проектная работа 4

### Задание 1. Планирование архитектуры

Для первого задания подготовлены три схемы, которые показывают поэтапное развитие MongoDB-инфраструктуры:

1. Шардирование MongoDB на два шарда.
2. Шардирование с репликацией каждого шарда.
3. Шардирование, репликация и Redis-кеширование.

| Схема     | Описание                                                                                                                                                                                                | Draw.io                                          | PNG                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------ |
| `schema1` | `pymongo-api` обращается к MongoDB через `mongos`, данные коллекции `somedb.helloDoc` распределяются между `shard1` и `shard2`, метаданные кластера хранит `configSrv`.                                 | [schemas/schema1.drawio](schemas/schema1.drawio) | [schemas/schema1.png](schemas/schema1.png) |
| `schema2` | Каждый шард представлен replica set из трех инстансов: `shard1-1`, `shard1-2`, `shard1-3` и `shard2-1`, `shard2-2`, `shard2-3`.                                                                         | [schemas/schema2.drawio](schemas/schema2.drawio) | [schemas/schema2.png](schemas/schema2.png) |
| `schema3` | Добавлен Redis-кеш. Приложение сначала проверяет Redis. При cache hit ответ берется из кеша. При cache miss данные читаются из MongoDB через `mongos`, возвращаются пользователю и сохраняются в Redis. | [schemas/schema3.drawio](schemas/schema3.drawio) | [schemas/schema3.png](schemas/schema3.png) |

### Задание 2. Шардирование

Реализация шардирования находится в директории [mongo-sharding](mongo-sharding).

Инструкция по запуску, инициализации MongoDB sharding и проверке результата описана в [mongo-sharding/README.md](mongo-sharding/README.md).

### Задание 3. Репликация

Реализация шардирования с репликацией находится в директории [mongo-sharding-repl](mongo-sharding-repl).

Инструкция по запуску, инициализации replica set для каждого шарда и проверке результата описана в [mongo-sharding-repl/README.md](mongo-sharding-repl/README.md).

### Задание 4. Кеширование

Реализация шардирования, репликации и Redis-кеширования находится в директории [sharding-repl-cache](sharding-repl-cache).

Инструкция по запуску, инициализации MongoDB, проверке Redis и замеру повторных запросов описана в [sharding-repl-cache/README.md](sharding-repl-cache/README.md).
